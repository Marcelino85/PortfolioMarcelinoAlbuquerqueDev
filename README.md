Aplicação Full Stack para organização, compartilhamento e leitura online de livros em PDF diretamente no navegador, com controle de privacidade (público/privado), propriedade de arquivos, autenticação JWT e modo claro/escuro.

## 🛠️ Stack Tecnológica

- **Frontend:** React.js, JavaScript (ES6+), HTML5, CSS3, Bootstrap, Axios, React Router DOM
- **Backend:** Node.js, Express.js, Python (FastAPI, Pandas, NumPy), APIs REST, JWT, Multer
- **Banco de Dados & Cloud:** MySQL, PostgreSQL, Firebase, AWS (EC2, S3, Lambda, Amazon Connect, Lex)
- **Ferramentas & Sistemas:** Git, GitHub, Linux (Ubuntu), ERP Sankhya, ServiceNow
